# 個人手繪旅遊手帳地圖海報生成器（Retro Travel Scrapbook Map）開發與擴充規範

## 1. 專案架構（多頁面方案 B）
- **首頁 (`index.html`)**：旅行明信片總覽牆，自動展示所有已生成的旅程卡片與跳轉入口。
- **獨立旅程海報 (`trips/[city].html`)**：每次新增一趟旅遊，必須在 `trips/` 資料夾下獨立生成該地點的手繪海報分頁，並自動更新首頁 `index.html` 的明信片連結。
- **照片管理 (`photos/[city]/`)**：照片統一存放於 `photos/[city]/` 資料夾中（禁止中文檔名或空格）。

## 2. 動態地域主題引擎與文化插畫貼紙庫
- **動態地域分析**：AI 必須即時分析地點歷史與復古視覺文化，動態設計專屬復古色票（低飽和暖色系）、地圖 SVG 與文化插畫貼紙。
- **純圖樣插畫貼紙規範**：僅使用純物品／食物／地標圖案的插畫貼紙，**嚴禁生成任何文字框標籤貼紙**。
  - **細節要求**：插畫須具備低飽和復古色調、細膩筆觸（`stroke-width="1.2"`）、`<linearGradient>` 漸層高光與鋼筆排線陰影細節，拒絕粗黑線簡筆畫風，並確保物件比例正確。
  - **文化映射範例**：日本使用抹茶聖代、狐狸繪馬、千本鳥居、團子；台灣使用大同電鍋、藍白拖、茄芷袋、珍奶。

## 3. 100% 保留使用者原始輸入（Data Integrity）
- 必須 **100% 原汁原味保留** 使用者輸入的文字內容，嚴禁擅自改寫、潤飾或刪減。
- 若使用者未提及食物，則自動隱藏該卡片的「美食清單」區塊。

## 4. 一圖流海報與卡片視覺規範
- **純 SVG 一體化地圖**：地圖輪廓、虛線時間動線與景點圖釘（`<circle>`、`<text>`）必須統一在同一個 `<svg viewBox>` 內繪製，禁止使用外部 HTML `position: absolute` 疊加，以確保座標零誤差。座標標籤須限制在畫布 15%～85% 安全區域內避免裁切。
- **SVG 圓潤白邊貼紙濾鏡（禁止粗黑邊）**：必須使用 SVG `<filter>`（利用 `<feMorphology operator="dilate" radius="3">` 搭配 `<feFlood flood-color="#ffffff">` 與 `<feComposite operator="in">`）製作純白、柔和且平滑的 die-cut 貼紙外框。**絕對嚴禁擴張出粗黑邊框**。
- **精緻插畫質感與筆觸規範**：拒絕粗糙色塊與粗黑邊線（禁止使用大於 1.5px 的黑色描邊）。所有插畫必須採用低飽和復古暖色系、細膩手繪筆觸（使用深咖啡色 `#5c4938` 代替純黑，`stroke-width="1"`）、柔和漸層光影與精緻細節。
- **嚴格防遮擋與貼紙定位規則**：
  - **絕對禁止**將貼紙放在卡片左上角或任何會遮擋標題、時間、Memo 文字或心情印章的位置。
  - 所有裝飾貼紙必須統一限制放置在 **「拍立得照片下方的白色寬邊空白處（右側）」** 或 **「整張卡片最底部留白處」**，並確保卡片內部有足夠的安全邊距（padding），100% 絕對不會壓到景點標題（如路思義教堂、金閣寺）或任何文字。
- **心情標籤（Mood Tag）與 Memo 標題列規範**：
  - **結構要求**：Memo 便條紙頂部必須設計為獨立的標題列（Header），使用 `display: flex; justify-content: space-between; align-items: center; margin-bottom: 12px;`。
  - **內容配置**：標題列左側顯示「MEMO」標籤，右側顯示微傾的蓋章式心情印章（Mood Stamp）。
  - **防遮擋規則**：印章與標籤必須限制在標題列內，**嚴禁使用 absolute 定位壓在 user-text 內文上**。內文必須從標題列下方開始排版，確保 100% 絕對不與任何文字或印章重疊。
- **拍立得相框**：強制自適應照片尺寸，背景白色，具備復古底片日期戳記或蠟印，確保無不自然空白邊。

## 5. AI 執行與擴充 SOP
1. 確認圖片路徑，分析地點文化，生成專屬色票與地圖 SVG。
2. 依照京都範本（`trips/kyoto.html`）的 CSS 濾鏡與架構生成獨立分頁。
3. 嚴格遵守插畫品質與防遮擋定位規則。
4. 輸出 `trips/[city].html` 並更新 `index.html`。

## 6. 基準範本參考（Few-Shot Reference）
未來每次新增或修改任何城市的旅遊日誌時，必須優先讀取 **`trips/kyoto.html`** 作為架構、CSS 濾鏡、SVG 地圖精準度與視覺精細度的基準範本，確保全站風格高度統一。
